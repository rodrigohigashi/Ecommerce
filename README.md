# E-Commerce Sales Prediction 👚👗📊

This repository contains a machine learning project that applies **linear regression** to predict sales in an e-commerce clothing store. The project is fully documented in two languages:

- 📁 [`PT/`](./PT/): versão em português do projeto
- 📁 [`EN/`](./EN/): English version of the project

The analysis includes R² (coefficient of determination), cross-validation, and error metrics to evaluate the model’s performance.

Both versions use the **same dataset**, which can be found in the [`data/`](./data/) folder.
